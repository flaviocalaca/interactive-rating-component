    # Frontend Mentor - Interactive rating component

    Esta é a minha solução para o desafio do [Interactive rating component no Frontend Mentor](https://www.frontendmentor.io/challenges/interactive-rating-component-koxNkrdu5c).

    ## 📌 Visão geral

    ### O desafio

    Os usuários devem ser capazes de:

    - Visualizar o layout ideal para a aplicação dependendo do tamanho da tela do dispositivo (Responsivo).
    - Ver os estados de hover em todos os elementos interativos da página.
    - Selecionar e enviar uma classificação numérica (de 1 a 5).
    - Ver o estado do cartão de "Thank you" após enviar uma classificação.

    ---

    ## 🛠️ Meu processo

    ### Tecnologias utilizadas

    - HTML5 semântico
    - CSS3 (Flexbox, variáveis e layouts responsivos com `max-width`)
    - JavaScript ES6+ (Manipulação de DOM, escutadores de eventos e template literals)

    ### O que eu aprendi

    Neste projeto pude praticar conceitos fundamentais do desenvolvimento web front-end:

    1. **Manipulação do DOM com JavaScript:**
       Utilização de `querySelector` e `querySelectorAll` para capturar elementos e interagir com eles.
    2. **Escuta de Eventos:**
       Uso de `addEventListener` para capturar os cliques nos botões de nota e o envio (`submit`) do formulário.
    3. **Alternância de Classes:**
       Gerenciamento da visibilidade das telas e destaque dos botões usando `classList.add()` e `classList.remove()`.
    4. **Layouts Responsivos:**
       Substituição de larguras e alturas fixas por `max-width` e `width: 100%`, garantindo um visual agradável em dispositivos móveis e desktops.
